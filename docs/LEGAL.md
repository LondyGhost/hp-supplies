# 法律与合规说明（发布前风险评估）

> 本文档说明本项目的知识产权属性、发布前的合规处理，以及各法域下互操作实现的
> 一般法律基础。它不构成法律意见；如您面临具体权利主张，请咨询执业律师。

## 1. 项目性质：独立互操作实现

- 本项目代码全部为原创（MIT 许可），**未复制、未反编译、未再分发**任何 HP 软件
  的代码、二进制、图标、文档或其它受版权保护的材料。
- 协议认知来源（按权重排序）：
  1. **公开资料**：HP 长期公开发布 LEDM XML Schema 相关文档（HP 开发者门户），
     LEDM/eSCL 是 AirPrint 生态的组成部分，第三方项目（如 `ipp-usb`、SANE 的
     `hp-ledm`/eSCL 后端、AirScan）早已公开实现同类协议；
  2. **对自有设备的接口行为观察**：观察自行购置的打印机在 USB 总线上的公开
     行为（枚举、端点、响应），并做了独立记录（见 `docs/protocol.md`）；
  3. Windows 版 HP 工具仅用于**行为对照验证**（确认数据一致性），其内部实现
     未被复制到本项目。
- 上述方式属于业界通行的"观察法/黑盒互操作"（如 Sega v. Accolade 一案确立的
  clean-room 邻近实践），产出的是不受他人版权约束的原创表达。

## 2. 未涉及技术保护措施的规避

- LEDM over USB 通道在设计上**无需认证**（同厂商 Windows 工具亦直接访问）。
- 本项目**只读**：仅发起 HTTP GET 查询设备状态 XML；不写入、不改固件、
  不参与原装耗材认证（"HP+"等）的破解或绕过。
- 因此不落入各国"规避技术保护措施"条款（如美国 17 U.S.C. §1201(a)、
  中国《著作权法》第 49/50 条相关义务）的规制范围。

## 3. 逆向工程在各法域的一般基础

| 法域 | 依据 | 说明 |
|---|---|---|
| 中国 | 《计算机软件保护条例》第 24/27 条；反向工程属合法获取软件者的正当权利范畴 | 本项目甚至未反编译任何软件，仅为设备接口观察，风险更低 |

| 其他 | 多数法域对互操作目的的逆向有类似豁免或实践 | 发布前请自行确认所在地法律 |
